# on7o
An AI personal device for Tought Organization

## Hardware
- M5StickS3
- Android Phone

## Software resource
- M5StickS3 connection with an Android Phonethru bluetooth
- Push to talk from M5StickS3 (with blue button), and audio transmission to Phone
- Phone connection with cloud, with audio transmission to a server
- Server handles STT an LLM interpretation, also persists text conversion and LLM interpretation
